## Energy-based modeling and sampling

An energy function scores candidate states; under a Boltzmann model, lower-energy states have greater probability, with the partition function providing normalization. Maximum-entropy inverse reinforcement learning models demonstrated trajectories this way and can compose multiple constraints by adding their energies [[D18]]. Guided cost learning approximates the intractable partition function with importance sampling and minimizes a KL divergence so its sampling policy produces low-energy examples [[D05]].

The energy defines a distribution; a sampler attempts to draw from it. Contrastive divergence uses short MCMC or Langevin chains to obtain negative samples [[D08]]. In one reported experiment, K=10 chains trained with the maximum-likelihood loss alone failed to reach low-energy modes, and differentiating through the rollout with a sampler-KL objective was reported as necessary [[D03]]. This is a finite-run finding, distinct from the asymptotic SGLD result that calibrated-noise Langevin trajectories sample the exact Boltzmann posterior as the step size tends to zero and iterations tend to infinity [[D16]]. One concept-learning model combines contrastive maximum-likelihood and rollout-differentiated sampler-KL losses for execution-time generation and identification [[D09]].

## Textual gradients and distinctions

Textual-gradient methods use a critic to diagnose failures and provide natural-language directions for iteratively editing language artifacts [[D10]][[D17]]. This differs from numerical inner-loop adaptation: MAML backpropagates through gradient-descent updates to adapt parameters [[D06]], whereas textual gradients guide edits to discrete language. For wiki compilation, one described adaptation uses pairwise relation critiques to create explicit bidirectional wiki links [[D04]]. Pairwise relational reasoning can represent interactions missed by independent entity encoders, but is a model computation, not textual-gradient editing [[D11]].

Both families involve iterative improvement, but differ in what is updated and how: energy-based methods model and sample states using numerical procedures, while textual-gradient methods revise language using critic-generated edits. The link-generation example connects textual critique to wiki structure; it does not make that editing procedure an energy-based sampler [[D04]][[D09]].
